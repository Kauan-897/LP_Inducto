# Landing Page — Inductotherm Group Brasil (Long Products)

Landing page estática (HTML, CSS e JavaScript puro) para captação de orçamentos das soluções de indução para linhas de revestimento.

- `index.html` — estrutura da página
- `styles.css` — estilos e responsividade
- `script.js` — cards de produtos, formulário (envio via WhatsApp) e modal das redes sociais
- `assets/` — imagens usadas na página
- `Home.png` / `Nossos serviços.png` — layouts de referência

Para ver localmente, abra o `index.html` no navegador ou rode `python -m http.server` nesta pasta.
